# Light Curve Analysis of the Trans-Neptunian Object Bienor

## 📌 Description

This project focuses on the **derivation and analysis of the light curve** of the trans-Neptunian object **Bienor**, based on observational data collected on **20 February 2026**.

The workflow includes:

* Image reduction and calibration
* Source extraction
* Photometric measurements
* Construction of the light curve

---

## 🛰️ Scientific Context

Trans-Neptunian objects (TNOs) are bodies located beyond Neptune's orbit. Studying their light curves allows us to:

* Estimate rotation periods
* Infer shape and surface properties
* Detect possible binaries or irregularities
